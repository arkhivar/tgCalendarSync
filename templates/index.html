Multiple Users

The application now supports monitoring calendars for multiple users:

  • Monitor several employees' calendars
  • Track changes made by external users to shared calendars
  • Organize notifications by user in Telegram supergroup topics

Each calendar requires its own Google API credentials.

Telegram Supergroups

For multiple users, you can use Telegram supergroups with topics:

  1. Create a Telegram supergroup and enable topics feature
  2. Create separate topics for each user (e.g., by user initials)
  3. Add your bot as an administrator of the supergroup
  4. Each user's calendar changes will post to their dedicated topic
