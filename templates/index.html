Google Calendar

The application will monitor your Google Calendar for:

  • New events added
  • Existing events modified
  • Events deleted

You'll need to provide Google Calendar API credentials to enable monitoring.

Telegram

Changes detected in your calendar will be sent as notifications to your Telegram account.

You'll need to:

  1. Create a Telegram bot using @BotFather
  2. Get your chat ID (you can use @userinfobot)
  3. Enter these details in the settings
