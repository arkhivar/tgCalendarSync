Setup Guide

Step 1: Create OAuth Client Credentials

  1. Go to the Google Cloud Console Credentials page
  2. Create a new project (or select an existing one)
  3. Enable the Google Calendar API for your project
  4. Create OAuth 2.0 Client ID (select "Web application" type)
  5. Set Authorized redirect URIs to match this application's domain (e.g., https://your-domain.com/auth/google/callback)
  6. Download the JSON file and paste the entire contents into the form

Step 2: Complete OAuth Authorization

  1. After submitting the form, you'll be redirected to Google's login page
  2. Sign in with the Gmail account that has access to the calendars you want to monitor
  3. Grant permission to view your calendars
  4. You'll be redirected back to this application with proper authentication complete
Important: The Gmail account you authorize must have access to the calendars you want to monitor.

If you're using a Telegram supergroup with topics:

  1. Create a topic in your supergroup for each user (e.g., using their initials or name)
  2. Enter the exact topic name in the "Telegram Topic Name" field
  3. Make sure to enable the "This is a supergroup with topics" option in the main settings
Important: The topic name must match exactly what you've created in Telegram (case-sensitive).
