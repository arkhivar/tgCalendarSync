Setup Guide

  1. Open Telegram and search for @BotFather
  2. Start a chat and send the command /newbot
  3. Follow the instructions to create a new bot
  4. Once created, BotFather will give you a token - copy this to the Telegram Bot Token field
  5. Start a chat with your newly created bot
  6. To get your chat ID, talk to @userinfobot and copy the ID to the Chat ID field

  1. In Telegram, create a new group by tapping the new message icon (on mobile) or the hamburger menu (on desktop)
  2. Add your bot to the group as an administrator
  3. Go to group settings and enable "Topics" to convert it to a supergroup with forum-like topics
  4. Create topics for each user you want to monitor (use their initials or names)
  5. Get the supergroup's chat ID (you can forward a message from the group to @userinfobot)
  6. When adding users in this app, set their "Topic Name" to match exactly the topic name in Telegram
Tip: Make sure to give your bot admin rights in the supergroup so it can post to topics.
